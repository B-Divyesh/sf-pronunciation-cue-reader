Why pronunciation cues help

Fix words your voice mispronounces.

Correcting selected text works once. Searching a dictionary breaks your reading flow. A pronunciation cue remembers a spoken form without changing selected text.

Install the package

Install the Chrome extension.

  1. Download and unzip the extension package.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose “Load unpacked” and select the unzipped folder.
  4. Select text, then click the Say It Right icon.

Install this package with Chrome Developer mode. Store distribution is planned for a later release.
